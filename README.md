# Preprocessor
'mypreprocessor' is a custom C preprocessor tool that processes C source files by performing three essential preprocessing operations:

1)Comment Removal: Removes single-line and multi-line comments.
2)File Inclusion: Handles header file inclusion.
3)Macro Substitution:Replaces macros with their corresponding definitions.

After processing, the tool generates an extended source file with a `.i` extension, similar to the output produced by a standard C preprocessor.
